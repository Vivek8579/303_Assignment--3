# 📌 DSA Campus Navigation & Utility System (Java)

This repository contains a compact, fully functional Java implementation of multiple Data Structures and Algorithms related to tree and graph operations.  
The entire solution is written in **under 150 lines** while maintaining full logic and correctness.

---

## 🚀 Features Implemented

### ✔ Binary Search Tree (BST)
- Insert buildings  
- Inorder traversal  

### ✔ AVL Tree
- Self-balancing insertions  
- Height maintenance  
- Rotations handled automatically  
- Inorder traversal  

### ✔ Graph Module
- Adjacency List representation  
- Add weighted edges  
- Breadth-First Search (BFS)  
- Depth-First Search (DFS)  

### ✔ Shortest Path
- **Dijkstra’s Algorithm** using priority queue  
- Returns distances from the source node  

### ✔ Minimum Spanning Tree (MST)
- **Kruskal’s Algorithm** implemented using Union-Find  
- Computes total minimum cost  

### ✔ Expression Tree
- Infix ➝ Postfix conversion  
- Build expression tree  
- Evaluate expression result  

---

## 🧪 Example Operations in the Program

When running the program, it will output:

- BST Inorder Traversal  
- AVL Inorder Traversal  
- BFS & DFS traversal from building 10  
- Shortest path results from Dijkstra  
- MST total cost using Kruskal  
- Expression evaluation result
